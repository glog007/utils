BrainxRCS

A minimal HTML demo for a Brain Repo/Config Service (BrainxRCS)

About

BrainxRCS is a conceptual UI for managing repository-like configs and quick snippets. This file is a simple static demo you can open locally.

Quick start

  1. Save this file as brainxrcs.html in your project.
  2. Open it in your browser to view the demo.

Example config

{
  "name": "brainxrcs",
  "version": "0.1.0",
  "features": ["snapshots","apply","diff"]
}

Want a custom theme or interactivity? Tell me what you need and I can extend it.

Commands

Open
Double-click or use your editor's preview

Or run bash ./serve.sh 8000 and open http://<HOST_IP>:8000/brainxrcs.html — see ACCESS.md for details.
